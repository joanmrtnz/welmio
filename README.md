# Welmio

Cross-platform personal finance application built as a mobile-first product.

## Tech stack

- React Native (Expo)
- Next.js (marketing and account pages)
- Node.js API
- Database layer (to be defined)
- CI/CD with GitHub Actions


## Architecture overview

This is a mobile-first product.

- The core application is built with React Native (Expo) and runs on iOS, Android and Web.
- A separate web application built with Next.js is used for the marketing site and account-related pages.
